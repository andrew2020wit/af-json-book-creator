JSON Book Creator

Create books for Foreign Reader from text and EPUB files, and edit existing JSON books. Files are processed in your browser and never uploaded.

Import files

Convert .txt and .epub files. One file opens in the editor, and its .to-translate.docx is downloaded; several files are converted and downloaded right away.

Edit JSON file

Open a .book.json file to change its title, headers and bookmarks.
